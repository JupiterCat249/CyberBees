# 功能按钮图标（右下角按钮区）

> 最后更新：2026-09-17（**提取算法已重做**）
> 来源：`电子蜂A5策划案/Figma设计/电子蜂对战空间 (1)/横版UI底座.svg` 右下角 4 个 80×80 按钮内

## 提取方式（重做后）
**不再自写几何管线**（旧做法会破坏原始信息：把贝塞尔/圆弧**离散成折线**、按容差 0.35px **抽稀顶点**、
合并近点 —— 曲线语义丢失）。现改为：
1. 从 SVG **按按钮归组**取出图标的**原始元素**（`<path>` / `<circle>`，**属性原样保留，零近似**）
2. 写成独立 SVG（`svg_src/N_name.svg`，`viewBox` 即按钮的 80×80 区域）
3. **用真正的 SVG 渲染器（headless Chrome）按原始矢量渲染** 8× 超采样 → LANCZOS 降采样为 80×80 PNG

> ⚠️ **必须继承根元素的 `fill="none"`**：设计稿根 `<svg ... fill="none">`，未显式声明 `fill` 的
> 描边元素靠**继承**才不填充。提取出的子 SVG 若漏掉该属性 → 描边图标会被**默认填成黑色实心块**
> （本轮踩过：差异一度 8.05%）。

- 按钮本体：80×80，圆角 10，底 `#FFFFFF-50%`；内描边 76×76 圆角 8 `#FFFFFF-10%`
- 4 个按钮左上角：**(1540,960) (1630,960) (1720,960) (1810,960)**（步距 90）

## 使用说明（Godot）
```gdscript
var icon := TextureRect.new()
icon.texture = load("res://assets/ui/func_icons/func_1_settings.png")
icon.position = Vector2(1540, 960)          # 与按钮左上角完全重合
icon.size = Vector2(80, 80)
icon.mouse_filter = Control.MOUSE_FILTER_IGNORE
```
