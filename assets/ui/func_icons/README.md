# 功能按钮图标（右下角按钮区）

> 最后更新：2026-09-17（提取算法重做 + 补回缺失元素）
> 来源：`电子蜂A5策划案/Figma设计/电子蜂对战空间 (1)/横版UI底座.svg` 右下角 4 个 80×80 按钮内

## 提取方式
1. 从 SVG **按按钮归组**取出图标的**原始元素**（`<path>` / `<circle>`），**属性字符串原样保留、零近似**
2. 写成独立 SVG：`svg_src/N_name.svg`（`viewBox` = 该按钮的 80×80 区域）
3. **用真正的 SVG 渲染器（headless Chrome）按原始矢量渲染**：8× 超采样 → LANCZOS 降采样为 80×80 PNG

## ⚠️ 三个必须注意的坑（均实际踩过）

### 1. 不能自写几何管线
旧做法把贝塞尔/圆弧**离散成折线**、按容差 0.35px **抽稀顶点**、合并近点 → 曲线语义丢失。
**必须交给真正的 SVG 渲染器**。

### 2. 必须继承根元素的 `fill="none"`
原稿根是 `<svg ... fill="none">`，未显式声明 `fill` 的**描边**元素靠继承才不被填充。
子 SVG 漏掉该属性 → 描边图标被**默认填成黑色实心块**（差异一度 8.05%）。

### 3. 极短路径会被"点数不足"过滤掉（表情的眼睛就是这么丢的）
眼睛的原始数据是一条**极短**路径：
```svg
<path d="M1661.43 994.643V995.011M1678.22 994.643V995.011" stroke="#303030" stroke-width="6"/>
```
两个笔画高仅 **0.368px**（靠 6px 描边宽度才成形）。解析器在**合并近点**时把它塌缩成单点，
再因"点数 < 2"被丢弃 → 表情图标**只剩嘴**。
**处理**：分组可用解析器算包围盒，但**输出必须回退到原始 XML 元素**，确保一个元素都不丢。

## 按钮区几何（设计坐标，1920×1080）
- 按钮 80×80 圆角 10 底 `#FFFFFF-50%`；内描边 76×76 圆角 8 `#FFFFFF-10%`
- 四按钮左上角 **(1540,960) (1630,960) (1720,960) (1810,960)**，步距 90

## 使用（Godot）
```gdscript
var icon := TextureRect.new()
icon.texture = load("res://assets/ui/func_icons/func_1_settings.png")
icon.position = Vector2(1540, 960)      # 与按钮左上角重合
icon.size = Vector2(80, 80)
icon.mouse_filter = Control.MOUSE_FILTER_IGNORE
```
