# 功能按钮图标（右下角按钮区）

> 最后更新：2026-09-17
> 来源：`电子蜂A5策划案/Figma设计/电子蜂对战空间 (1)/横版UI底座.svg`（右下角 4 个 80×80 按钮内）
> 提取方式：从 SVG **按按钮归组**取出图标矢量（`<path>` 描边/填充 + `<circle>`），
> 栅格化为 PNG（8× 超采样 + LANCZOS 缩小 ⇒ 抗锯齿）

## 按钮区几何（设计坐标，屏幕 1920×1080）
- 按钮本体：**80×80，圆角 10，底 `#FFFFFF-50%`**；内描边 **76×76 圆角 8 `#FFFFFF-10%`**
- 4 个按钮左上角：**(1540,960) (1630,960) (1720,960) (1810,960)**（步距 90）

## 使用说明（Godot）

```gdscript
var icon := TextureRect.new()
icon.texture = load("res://assets/ui/func_icons/func_1_settings.png")
icon.position = Vector2(16, 15)                       # 见上表偏移
icon.mouse_filter = Control.MOUSE_FILTER_IGNORE
```

### ⚠️ 两条硬注意
1. **颜色不在 PNG 里**：SVG 中颜色由 `stroke`/`fill` 给出（`#333333` / `#303030`）。
   本目录 PNG 已按该色栅格化为**深灰**；若按钮底改为深色，**需按设计规范重新着色**，不可直接沿用。
2. **`<circle>` 必须单独处理**：`func_2_emote` 的脸是 SVG `<circle>` 元素而非 path；
   仅扫 `<path>` 会**丢失脸型**（本轮即因此先产出过错误版本）。
