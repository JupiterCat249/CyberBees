# 卡牌与战斗界面系统 — 使用说明书

> 全部渲染基于 1920×1080 设计坐标系，窗口任意变化均等比缩放、比例永不变形。
> 本说明书对应 2026-09-07 版本。

---

## 1. 系统组成

| 场景 | 用途 | 运行方式 |
|---|---|---|
| `card_system/card_auto.tscn` | 单张卡牌（可复用单元） | 实例化到任意场景 |
| `card_system/card_demo.tscn` | 批量卡牌预览（4×4 填满地图区） | F6 或 F5 切主场景 |
| `card_system/battle_ui.tscn` | 战斗界面背景骨架（当前主场景） | F5 |

主场景当前为 `battle_ui.tscn`（只渲染背景，卡牌隐藏）；要调试卡牌时对 `card_demo.tscn` 按 F6，或临时把 项目设置 → 应用程序 → 运行 → 主场景 换回 `card_demo.tscn`。

## 2. 单张卡牌（card_auto.tscn）

实例化后**只改根节点检查器参数**，不要动内部节点。改完立即生效。

### 2.1 参数一览

**数字（-1 = 不显示，≥10 自动两位）**
| 参数 | 含义 |
|---|---|
| `cost` | 左上角费用（橙字黑底） |
| `stat_l1` / `stat_l2` | 左栏上/下数值 |
| `stat_r1` / `stat_r2` | 右栏上/下数值 |

**图标（-1 无 · 0攻击 · 1速度 · 2血量 · 3射程 · 4兵蜂 · 5建筑 · 6指令 · 7蜂王）**
| 参数 | 位置 |
|---|---|
| `icon_l1` / `icon_l2` | 左栏数值下方 |
| `icon_r1` / `icon_r2` | 右栏数值下方 |
| `icon_tag` | 右上角类别图标 |

**素材**
| 参数 | 含义 |
|---|---|
| `art` | 中央立绘（Texture2D，拖入 PNG） |
| `tag_texture` | 自定义类别图标（可选，优先于 `icon_tag`） |
| `art_fit` | 0=完整显示（contain）· 1=裁剪铺满（cover，默认） |

**配色**（`col_base` 卡底 / `col_cell` 数值格淡灰 / `col_band` 横带 / `col_cost_bg`·`col_cost_num` 费用格 / `col_num` 数字 / `col_icon` 侧栏图标 / `col_tag_bg`·`col_tag_icon` 类别格 / `col_center` 中央底 / `col_stripe` 条纹色）

**微调**
| 参数 | 含义 |
|---|---|
| `art_zoom` | 立绘放大倍率（默认 1.0，范围 1.0~2.0，已固化） |
| `icon_scale` / `tag_icon_scale` | 图标缩放 |

### 2.2 类别底纹（自动，由 `icon_tag` 决定）

| 类别 | 中央底纹 |
|---|---|
| 兵蜂(4) | 纯色浅灰，无条纹 |
| 指令(6) | 灰白条纹（3px 粗 = 3px 间隔） |
| 蜂王(7) | 金色条纹 |
| 建筑(5) | 淡棕条纹 |

条纹只画在底层，立绘永远覆盖在条纹之上。

## 3. 批量渲染（card_demo.gd）

编辑 [card_demo.gd](card_demo.gd) 顶部的 `DATA` 数组，一条数据 = 一张卡：

```gdscript
{"art": "卡牌d1-巡航导弹", "cost": 6, "tag": 6,
 "l1": 5, "li1": 0, "li2": 1,     # 左栏：数值5 + 攻击图标 + 速度图标
 "r1": -1, "ri1": 2, "r2": 3, "ri2": 3},  # 右栏：无数值 + 血量图标 / 数值3 + 射程图标
```

- `art` 填 `card_system/art/` 下的文件名（不含 `.png`）
- 数据不足 16 张时自动循环复用，凑满 4×4
- 布局常量（一般不用改）：`COLS=4`、`GAP=250`、`CARD_COUNT=16`、`MAP_ORIGIN=(460,40)` —— 16 张正好无缝填满居中的 1000×1000 地图本体

## 4. 战斗界面（battle_ui）

- 整幅界面由 **1 个 shader**（[battle_ui.gdshader](battle_ui.gdshader)）程序化绘制，全部布局为 shader 内定量常量，改常量即改布局
- 已绘制：地图 1008×1008（含描边，本体 1000×1000，格 250×250）+ 十字网格、左右手牌面板 400×400、六边形徽章（左右各自列左缘，数字留白）、卡牌详情黑块 300×300、状态图标（复用卡牌图集）、主按钮 400×100、右下 4 个功能按钮（图标纯 SDF）
- **文字与数字一律未画**：等合作伙伴的游戏逻辑函数接入后，在 `Holder` 下加文本节点即可（会跟随等比缩放）
- 通用样式：圆角 10px、内描边 4px

## 5. 比例锁定机制（自动，无需配置）

- 项目设置：`canvas_items` + `keep`，基准 1920×1080
- 独立窗口拖拽时自动吸附 16:9；非 16:9 屏幕（如 2880×1800）全屏时上下出黑边——这是"比例绝不变形"的代价
- **Godot 编辑器内嵌游戏面板不应用项目拉伸**（按面板尺寸 1:1 渲染），所有场景已内置 holder 自适应：任何窗口下内容等比缩放居中，不会出现"只渲染一个角"

## 6. 素材要求

- **立绘**：`card_system/art/`，PNG，建议 ~500×500 方形（高分辨率会自动降采样）；新 PNG 放入后等 Godot 重新导入
- **类别图标**：`card_system/tag_icons/`（白色剪影）
- **图集**：`card_atlas.png`（数字 0-9 + 8 个图标）由 `tools/bake_card_atlas.gd` 烘焙；只有增改图标时才需要重烘焙
- 卡牌渲染 250×250，圆角用标准 `sd_round(p, b, r)`

## 7. 验证工具（命令行截图）

PowerShell：

```powershell
$env:CARD_SHOT = "D:\out.png"            # 输出路径（必填才有截图行为）
$env:CARD_W = "1152"; $env:CARD_H = "648" # 可选，默认 1920x1080
& "D:\Godot_v4.7.2-stable_win64.exe" --path "D:\godot game\新建游戏项目" res://card_system/battle_ui.tscn
Remove-Item Env:\CARD_SHOT
```

运行后自动定窗口 → 渲染 → 存 PNG → 退出。不设 `CARD_SHOT` 时就是正常运行。

## 8. 已知注意事项

1. **先关 Godot 编辑器再改脚本**（或在编辑器里关掉对应脚本标签页）：编辑器的脚本缓冲区会把外部修改静默覆盖回旧版，本项目已多次踩坑
2. 同一文件的多处修改要逐个来，不要并行（会相互覆盖）
3. 图集采样必须 `filter_linear`（禁 mipmap），否则图标出现灰边框
4. 黑屏问题：本机已把 Godot 设为 Intel 集显（Windows 图形设置）；若再遇 D3D12 黑屏，可加 `--rendering-driver opengl3` 启动
