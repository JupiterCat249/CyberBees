# 显像管特效 · 透明度（Alpha）设置方法

> 最后更新：2026-09-17
> 当前值：**α = 0.05（5%）**，符合策划案「电子管特效：`-5%`」
> 已把 α 收拢为**唯一入口**，改一处即可控制整个特效

## 一、节点结构（α 只在 `Mover` 一处）

```
BattleUI
└─ Background                              (Panel)
   ├─ TextureRect                         （背景图 bg_blurred.png）
   └─ CrtFx                               (Control, clip_contents = true)
      ├─ Mover                            (Control)  ← ★ modulate = Color(1,1,1,0.05)  α 唯一入口
      │   ├─ Sheet1                       (TextureRect)  y = -1080 ~ 0
      │   ├─ Sheet2                       (TextureRect)  y = 0 ~ 1080
      │   └─ Sheet3                       (TextureRect)  y = 1080 ~ 2160
      └─ CrtAnim                          (AnimationPlayer, autoplay = scan)
```

**原理**：Godot 的 `modulate` 是**向下乘算**的（子节点会继承父级的 modulate）。
所以把 α 放在 `Mover` 上，三张 Sheet **自动统一**受影响，不必逐张设置。

---

## 二、方法 1：编辑器里改（推荐，最直观）

1. 场景树选中 **`Background/CrtFx/Mover`**
2. 右侧**检视器**找到 **`CanvasItem → Visibility → Modulate`**
3. 点开颜色框，把 **`A`（Alpha）** 从 `0.05` 改成目标值
4. `Ctrl+S` 保存场景

> ⚠️ 不是 `Self Modulate`：`self_modulate` **只作用于本节点、不传给子节点**，
> 放在 `Mover` 上会**完全没有效果**（它会"看起来像改了"，但 Sheet 不受影响）。
> 认准 **`Modulate`**（无 `Self` 前缀）。

---

## 三、方法 2：直接改场景文件文本（适合批处理/脚本）

文件：`scenes/ui/battle_ui_alpha.tscn`
定位 `[node name="Mover" ...]` 块，改这一行：

```
modulate = Color(1, 1, 1, 0.05)
                          ↑ 第 4 个分量就是 alpha（0~1）
```

例：
| 目标 | 写成 |
|---|---|
| 3% | `modulate = Color(1, 1, 1, 0.03)` |
| 5%（当前） | `modulate = Color(1, 1, 1, 0.05)` |
| 10% | `modulate = Color(1, 1, 1, 0.10)` |
| 15% | `modulate = Color(1, 1, 1, 0.15)` |

> 也可写成十六进制：`modulate = Color("#ffffff0d")`（`0d` = 13/255 ≈ 5%）

---

## 四、方法 3：只想改某一张（一般不需要）

若确实要三张不同强度（例如制造分段差异），就把 `modulate` 分别写回各 Sheet：

```
[node name="Sheet1" type="TextureRect" parent="Background/CrtFx/Mover"]
modulate = Color(1, 1, 1, 0.05)     ← 单独设这张
...
```

或者运行时用代码（不推荐，改动会与场景不一致）：
```gdscript
$Background/CrtFx/Mover.modulate.a = 0.08          # 统一改
$Background/CrtFx/Mover/Sheet1.modulate.a = 0.12   # 只改一张
```

## 五、调参参考：α 与画面亮度的关系

扫描线亮带压在白 `#F9F9F9` 上、背景为 `#666666`(102) 时：

| α | 亮带亮度 | 相对 5% |
|---:|---:|---:|
| 0.03 | 106.4 | −2.7% |
| **0.05（当前）** | **109.4** | **±0** |
| 0.07 | 112.3 | +2.7% |
| 0.10 | 116.7 | +6.7% |
| 0.15 | 124.1 | +13.4% |

> 亮带与暗带差值固定为约 **+21**（α=0.05 时），α 越大对比越明显。

---

## 六、⚠️ 三条注意（都实际踩过）

1. **不要用 `Self Modulate`** —— 不传子节点，放在 `Mover` 上无效。
2. **不要在动画里加 `modulate` 轨做"呼吸脉动"** —— 曾因此产生"周期性透明度变化"的观感问题
   （α 0.05↔0.07 带来 +2.7% 周期性明暗，周期 1.5s）。
   策划案要求的是**固定** `-5%`。当前 `scan` 动画**只有 1 条 `Mover:position` 轨**，不含任何 modulate。
   如需改透明度，**改静态属性即可**，不要再加动画轨。
3. **改完确认 `Mover` 的 alpha 值**：`node_get_properties` 或检视器读回核对，
   避免改在 `Sheet` 上而 `Mover` 仍是旧值（两者会**相乘**）。
