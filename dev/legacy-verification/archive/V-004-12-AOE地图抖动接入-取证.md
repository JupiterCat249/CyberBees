## 改动（走 MCP）

`battle_deploy.gd` 的 `cmd_at()` —— 指令卡是**溅射/链式类技能**的通路，
在技能结算成功后按**命中数**触发地图抖动：

```gdscript
	var res: Dictionary = s.use_skill(str(c["name"]), cell)
	if not bool(res.get("ok", false)):
		s.refresh()
		return
	# 迭代004③：AOE 地图抖动 —— 命中 ≥2 处（溅射 / 链式传播）时抖地图
	if s.anim != null and (res.get("hits", []) as Array).size() >= 2:
		s.anim.shake_map()
```

**依据**：`BattleSkills.run_skill()` 返回 `{ok, reason, hits:[{cell,id,effects:[]}]}`（`hits` 逐命中累积，
链式传播同样 append）→ 以 `hits.size() >= 2` 判定 AOE ✅
**保护**：`s.anim != null` 空值保护；非 AOE（单目标）不触发 ✅
