## 排查结论

**磁盘代码正常**（`git diff --stat HEAD` 为空；`can_long_press` / `_long_press_allowed` /
`InputEventMouseMotion` / `can_support_at` / `long_pressed` 接线 / 场景 `PopupBox` 节点 全部在位），

**发现上一轮修复过度收紧**：
```gdscript
# 上一轮（错误）
return winner == "" and pending_kind == "" and armed_card < 0 and selected_unit < 0 and mode == D.Mode.IDLE
```
`selected_unit < 0` 意味着**点击单位本身就会选中它 → 状态永不空闲 → 长按详情浮窗永不弹出** ✗
—— 这正是人反馈的第 2 条现象（而"长按查看详情"恰恰是要长按单位）。

## 修正

```gdscript
# 现在：仅"有待确认 / 已持牌 / 处于部署·指令·支援目标选择模式"时禁止长按
return winner == "" and pending_kind == "" and armed_card < 0 and mode == D.Mode.IDLE
```
两个目标同时满足：
- **长按单位/手牌可以弹出详情**（选中态不再禁止）✅
- **支援确认期间仍禁止长按**（`pending_kind != ""` 即禁止）→ 不会抢走确认点击 ✅
