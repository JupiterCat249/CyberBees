## 方案B1 实现（走 MCP）

日志是**多行**、每行阵营词位置不定 → `Label` 无法行内染色 ✗ → 改用 **`RichTextLabel`** ✅

```gdscript
func _mk_log_rich() -> RichTextLabel:
	r = RichTextLabel.new()
	r.bbcode_enabled = true
	r.fit_content = false
	r.autowrap_mode = TextServer.AUTOWRAP_WORD_SMART
	r.mouse_filter = Control.MOUSE_FILTER_IGNORE                  # 不拦点击
	r.add_theme_stylebox_override("normal", StyleBoxEmpty.new())  # **清空底板**（防遮挡）
	r.position = Vector2(1494, 674); r.size = Vector2(760, 150)   # **显式尺寸**（Node2D 下不会自动撑开）
```
数据源**不分叉**：仍以 `_labels["log"]` 为唯一文本源，再交给 `_faction_bb()` 生成染色版 ✅
```gdscript
	_labels["log"].text = "\n".join(state.log_lines.slice(…))
	if _labels.has("logrich"):
		_labels["logrich"].text = _faction_bb(_labels["log"].text)     # 只把 绿方/红方 包上颜色标签
```
旧 `LogText`（Label）**保留但隐藏**（`visible=false`，便于回退）✅
