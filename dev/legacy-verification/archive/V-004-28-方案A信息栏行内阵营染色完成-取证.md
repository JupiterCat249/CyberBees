## 方案A 实现（走 MCP · 保持 `Label`，不换控件）

**思路**：信息栏**拆成三段独立 `Label`**，用**文本宽度测量**无缝拼接，只给中间的"阵营词"上色 ✅

```gdscript
const INFO_POS := Vector2(452.0, 4.0)
const INFO_FS := 26

_bind():
    _labels["info"]    = _mk_label("InfoBar",     INFO_POS, INFO_FS, …)   # 前缀：第N回合 · 阶段:X ·
    _labels["faction"] = _mk_label("FactionText", INFO_POS, INFO_FS, …)   # **阵营词：N方**
    _labels["suf"]     = _mk_label("InfoSuffix",  INFO_POS, INFO_FS, …)   # 后缀：· 提示

_measure(text, fsize):                       # 用主题字体实测宽度，避免硬编码偏移
    f.get_string_size(text, HORIZONTAL_ALIGNMENT_LEFT, -1, fsize).x

_on_state_changed():
    pre = "第%d回合 · 阶段:%s · ";  fac = "%s方";  suf = " · %s"
    _labels["info"].text = pre; _labels["faction"].text = fac; _labels["suf"].text = suf
    _labels["faction"].add_theme_color_override("font_color", anim.turn_color(当前方))
    # 三段无缝拼接（结束态用半透明白）
    _labels["faction"].position = INFO_POS + Vector2(w_pre, 0)
    _labels["suf"].position     = INFO_POS + Vector2(w_pre + w_fac, 0)
```

**同时**（人的两点"不要"）：整条文字染色**已移除**；阵营底色**已移除**（不再创建 `TurnBg`）✅
