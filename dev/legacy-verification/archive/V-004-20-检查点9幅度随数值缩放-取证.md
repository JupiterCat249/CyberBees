```gdscript
## 幅度随数值缩放：以 4 点为基准线性放大，钳制在 [0.6x, 2.0x]（避免过小看不清 / 过大失稳）
func _scaled_amp(base: float, value: int) -> float:
	if value <= 0: return base
	return base * clampf(float(value) / 4.0, 0.6, 2.0)

func shake_unit(tgt: Node, value: int = 0) -> void     # 单位受击抖动（基准 6px）
func shake_map(map_node: Node = null, value: int = 0)  # AOE 地图抖动（基准 12px）
func _register_shake(pname, base_amp, value, frames)   # 按缩放幅度**就地重注册** Pattern
```

- 幅度属 **Pattern 数据**，故"缩放"通过**重注册**实现（同一 Pattern 名，内容按数值更新）✅
