## 二、问题①：后手额外回费的发放时机

### 根因
`battle_setup.prepare()` 在对战准备阶段直接赋值：
```gdscript
s.cost[order[1]] = D.SECOND_PLAYER_BONUS     # ← 开局（对战准备）就进了后手账户 ✗
```
→ 玩家在对战准备界面就能看到后手已有 2 费。

### 修正
| 位置 | 改动 |
|------|------|
| `battle_setup.gd` | **删除**开局赋值；改为登记 `second_bonus_pending = true`（并 `second_bonus_granted = false`），日志写明「待X方自己的回合开始结算（**仅此一次**；不会占用先手的回合）」 |
| `battle_turn.begin_turn()` | 当 `side != first_side` 且 pending 未发放时：`bonus = SECOND_PLAYER_BONUS` 并入该方回费，发一次日志「【后手额外回费】X方 +2（**仅此一次**，在自己的回合开始时结算）」 |
| `battle_state.gd` | 新增 `second_bonus_pending` / `second_bonus_granted` 两个标志（防重复发放、可追溯） |

### 实测（干净进程）
```
对战准备阶段：绿=0 红=0 ；pending=true
先手回合中  ：绿=2 红=0        ← 红（后手）仍不得提前拿到 ✓
后手回合开始：绿=2 红=4        ← 基础 2 + 额外 2 ✓
日志：【后手额外回费】红方 +2（**仅此一次**，在自己的回合开始时结算）／【回费】红方 +2 → 费用 4
下一轮后手回合：红 4 → 6（仅 +2 基础，无额外）✓
```
> 另一次运行（先手=绿）同样通过：`准备 0/0 → 先手回合 绿2/红0 → 后手回合 绿2/红4`。

## 三、问题②：详情栏生命值恒 0

### 根因（★ 一行硬编码）
`battle_state.focus_values()`（详情栏右侧 4 行数值的来源）在**非场上单位**（手牌卡）分支里：
```gdscript
return [str(int(d.get("atk", 0))), "0", str(int(d.get("spd", 0))), str(int(d.get("range", 0)))]
#                                    ↑ 第 2 项被写死为 "0"
```
而该栏第 2 行对应的**卡面图标是 `hp`**（框架 `card_auto` 中 `icon_r1 = I_HP`）——
即"生命值"位置被填了常量 0（原实现疑似把它当成"防御减免"），所以**恒显示 0** ✗。
（另有 `StatDef` 节点名同样误导，让人以为该行是"防御"。）

### 修正
```gdscript
# 场上单位分支：生命取实时 hp
return [str(final_atk(id)), str(int(units[id]["hp"])), str(final_spd(id)), str(final_range(id))]
# 手牌/卡面分支：生命取卡牌基础 hp（原为写死的 "0"）
return [str(int(d.get("atk", 0))), str(int(d.get("hp", 0))), str(int(d.get("spd", 0))), str(int(d.get("range", 0)))]
```
并把节点 `StatDef` **更名为 `StatHp`**（`battle_card.tscn` + `battle_detail_view.gd`），消除命名误导。

### 实测
| 场景 | `StatAtk / StatHp / StatSpd / StatRange` | 判定 |
|------|------------------------------------------|------|
| 选中场上蜂王（hp=8） | `7 / 8 / 1 / 2` | ✅ 生命=8（此前为 0） |
| 蜂王 hp 人为改 5 后 | `7 / 5 / 1 / 2` | ✅ 实时跟随 |
| 查看手牌「叶蜂」（hp=3） | `2 / 3 / 1 / 1` | ✅ 用卡牌基础生命 |
| 指令卡 | 走指令分支（`—/—/—/射程`） | ✅ 不显示生命 |

**截图复核**（`V-005.3-1-图-详情栏生命与后手回费日志.png`）：
左下详情块中，卡牌右侧数值栏为 **攻 7 / 生命 8 / 移 1 / 射程 2**（**不再是 0**）；
右侧日志区可见 【后手额外回费】红方 +2（**仅此一次**，在自己的回合开始时结算）与随后的【回费】行 ✅
