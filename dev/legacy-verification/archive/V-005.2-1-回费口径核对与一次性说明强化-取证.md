## 一、人提出的口径（2026-08-28）

> 「后手**不在先手的行动阶段**就回费，具体来说后手先手**都只能在自己的回合回费**，
> 只是后手会有**开局的额外回费**，但同样只发生自己的行动回合并**一次结算**，此后后手回费不再有额外的机制回费。」

拆成三条可验证断言：
1. 只有**当前行动方**回费；对方在其回合内**不得**获得任何费用；
2. 后手的额外回费是**一次性**的（只在开局发放一次）；
3. 此后双方的回费**只有**基础回费（+第 7 回合起 +2）与**资源建筑回费**，无其它额外机制。

## 三、运行时实测（干净进程 · `run_token=5`）

### 开局
```
对战开始：绿方先手 · 红方后手
后手开局额外回费：红方 0 → 2（**仅此一次**，此后按回合正常回费；且不占用先手的回合）
```
✅ 一次性性质在**发放时**即写明（改前只写"初始费用 +2"，易被误解为"每回合多给"）

### 连续回合的双方费用（每行 = 该回合结束、交到对方之前）
```
green方回合：绿 2→2  红 2→4     ← 绿的回合内 绿未涨（本回合已回费）；红的 +2 发生在红自己的回合开始
red方回合：  绿 2→4  红 4→4
green方回合：绿 4→4  红 4→6
```
✅ 每次费用增加都发生在**该方自己的回合**；数值恒为 **+2**（基础回费），**无额外加成**

### 先手回合内 · 后手费用是否变动（直证第 1 条）
```
先手回合开始时：绿=4 红=6
先手回合（部署+行动）结束时：绿=4 红=6 → 后手费用是否变动 = false ✅
```
