## 三、地图/背景解耦（信号 + 信号传参）

### 做法
```
BattleEngine.emit_map_assets()
      │  emit_signal(SIG_MAP_ASSETS, ArenaAssets 资源)
      ▼
BattleSignalBus.map_assets_changed(assets)
      │  同一条信号，两个订阅者各自取自己要的字段
      ├──────────────► Battle/MapView/MapPlate/TextureRect  ← assets.map_texture
      └──────────────► Background/TextureRect                ← assets.background_texture
```
- 两个 TextureRect **互不引用**：不持有对方指针，也不知道对方存在
- **换图只需引擎再广播一次**（`engine.load_map(md)`），两边自动跟着变
- 新增资源类 `scripts/battle/arena_assets.gd`（`ArenaAssets`）：
  `map_texture` / `background_texture` / `map_name` / `map_desc` / `has_map`

### 资源侧补齐（原本背景为空）
6 张地图资源**都补齐了 `background_texture`**（`assets/background/bg_blurred.png` 1920×1080）；
`terrain_texture` = `assets/background/map_terrain.png`（1000×1000，与棋盘区尺寸吻合）。
视图默认加载「默认」地图 → 地图板与背景**开局即有内容**。

## 四、两套 UI 参数资源（人要求：两者参数应不同）

| 资源类 | 管的区域 | 关键参数 |
|---|---|---|
| `scripts/data/detail_params.gd`（`DetailParams`） | 详情区 `HUD/InfoPanel` | 立绘槽 **300×300 原尺寸直放** · 卡名 38px · 描述 25px + 行距 · 四维 4 行（图标 24×24） |
| `scripts/data/hand_card_params.gd`（`HandCardParams`） | 手牌卡 `card_hand.tscn` | 卡 **200×200** · 立绘源图基准 **400×454 → 必须缩放+偏移裁剪** · 徽章 60×65 + 26px · 内描边 200×200 |

**为什么不共用**（量级差很大，是实测值）：
- 手牌卡只有 200×200，而立绘源图基准是 400×454（接近卡的两倍）→ 必须靠 scale + offset 把要的部分塞进裁剪窗；
- 详情区立绘槽直接是 300×300，原尺寸直放即可；且详情区还有卡名/描述/四维文字参数，手牌卡没有。
- 共用一套必然一边被裁掉或一边过小。

视图 `apply_params()` **分开应用**；自检断言「两套参数是不同对象」→ PASS。
