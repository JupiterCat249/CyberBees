## 改动（走 MCP）

### 1. 引擎新增**浮动数值文本**能力（`battle_anim.gd`）

```gdscript
func float_text(value: int, kind: String, at: Vector2, parent: Node = null) -> Node:
	# 用 D.digit_node 生成数字节点 → 挂到 fx_parent（Overlay）→ 用自身 Pattern 驱动"上浮+淡出"
	# 颜色：refund=#FFA300 / damage=#FF2000 / heal=#00DD00；**字号随数值**（text_size_for）
	lbl.set_meta("fx_once", true)     # 播完自释放（在 stop() 中 queue_free）
```
- 新增 Pattern `浮字上浮`（MOVE_BY 三段上浮 → TINT 淡出，**无前摇**）
- `stop()` 中对带 `fx_once` 标记的目标 `queue_free()`（一次性特效自清理）
- 引擎补 `const D := preload(battle_defs.gd)`（本轮暴露：原先未预载 ✗）
- **协调器注入 `fx_parent = _ci("Overlay")`**（本轮暴露：原先未注入 → `float_text` 恒返回 null ✗）
