```gdscript
if int(side) != my_seat:
    return Color(0.22, 0.22, 0.22, 1)      # 敌方 → 一律黑

    return Color(1, 1, 1, 1)               # 我方且轮到我 → 白

```

### ② 手牌区滤镜（改动前＝**费用口径**驱动，非"按行动方"）

**产物**：`diag_match_settled_2026-10-14 19-58-03.txt:124-131`（`my_seat=0`、`active=0`、本方费用 4）。

```
手牌 side=0 #1 modulate=(1.000,1.000,1.000,1.00)   ← 费用 2 ≤ 4 够
手牌 side=0 #2 modulate=(1.000,1.000,1.000,1.00)   ← 费用 3 ≤ 4 够
手牌 side=0 #3 modulate=(0.650,0.650,0.650,1.00)   ← 费用 5 > 4 不足
手牌 side=0 #4 modulate=(0.650,0.650,0.650,1.00)   ← 费用 8 > 4 不足
手牌 side=1 #1..#4 modulate=(0.220,0.220,0.220,1.00)  ← 非本方 → 一律黑
```

**逐行读法（重要，避免误读为"第三种形态"）**：

| 行 | 对象 | modulate | 由什么决定 |
|---|---|---|---|
| `#1`/`#2` | 本方手牌（side=0） | **1.000 白** | 本方手牌 · 费用够（2≤4、3≤4） |
| `#3`/`#4` | 本方手牌（side=0） | **0.650 中性灰** | 本方手牌 · 费用不足（5>4、8>4） |
| `#1..#4` | 对方手牌（side=1） | **0.220 黑** | **非本方 → 一律黑**（不看费用） |

⇒ 改动前手牌口径实为「**本方**：费用够 → 白 / 不足 → **中性灰 0.65**；**非本方** → **一律黑 0.22**」，
即**费用与阵营两条判据混在一起**（`_render_hand` 里 `aff = hand_affordable(...) and my_turn and side == my_seat`，
再以 `dim_black = side != my_seat` 决定灰/黑）。三档取值（1.0 / 0.65 / 0.22）是**同一口径的三个取值**，
不是三种互相矛盾的形态；本档 ① 节"一律黑"一句专指**敌方手牌**（side=1）那一档。

> ⚠️ **勘误（2026-10-14 修订）**：本档初版把这一档简写成"我方 1.0 / 敌方 0.22"，**遗漏了"后两张 0.65 灰"**，

## 三、本次基线一并发现的既存现象（与本轮三条口径无关）

### 3.1 手牌视图字典以卡牌 id 作键

`arena_view._hand_nodes` / `_hand_order` 以 `data.id`（`CardData.id`，卡池内唯一）作字典键。
当两侧手牌含同名卡时（联机常态），两个字典的**键集相同**。

**身份判定（2026-10-14 实测，别名实验）**：
往 `engine.state.sides[0]["hand"]` 追加一个元素后，`sides[1]["hand"].size()` **不变**（4→4），
随后 `pop_back()` 复原成功 ⇒ **两侧手牌数组不是同一个 Array 对象**（不构成别名）。
两侧读到同一批卡 id 的原因＝**卡牌定义实例在卡池内唯一**（双方同名卡引用同一批 `CardData`）。

> ⚠️ **分歧留痕**：独立评估者的复跑报告称「`sides[0].hand` 与 `sides[1].hand` 为同一 Array 实例」，
> 与本档的别名实验结论**相反**。两说并列，以本档实验（有 append/pop 读数）为准，但不排除评估者
> 使用了不同的读法（如对 `.duplicate()` 副本取样）。该分歧**不影响本轮三条口径**：
> 滤镜读数按**面板子节点**取值，不经过这两个字典。

### 3.2 `arena_view` 有两个座位字段

`net_seat`（来自 `NetSession.seat`，联机座位号）与 `my_seat`（视图视角字段，仅由 `set_my_seat()` 赋值）。
两者在单机/未经 `set_my_seat()` 时可能不同步。**本轮所有座位相关读数一律以 `my_seat` 为准**
（`NetDiagDump §F` 读的也是 `cs.get("my_seat")`）。
