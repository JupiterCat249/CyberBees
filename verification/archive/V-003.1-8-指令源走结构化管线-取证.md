## 改动

### 删除的硬编码（`battle_state.cmd_at()` 原实现）

```
if c.has("heal"):      units[tid]["hp"] = mini(... + c["heal"], target["hp"])   # 治疗硬编码
else:                  dmg = c.get("dmg", 0)；command_x 时 dmg = cost*2          # 伤害硬编码
                       if c.has("debuff"): add_effect(tid, c["debuff"])         # 减益硬编码
```
以上分支**整体删除**，改为单一入口：

```gdscript
var res: Dictionary = use_skill(str(c["name"]), cell)   # 走 [源]→[条件]→[倍率]→[对象]→[效果]
if not bool(res.get("ok", false)): refresh(); return     # 未生效则不扣费、不弃卡
cost[current] -= pc; grave[current].append(c); hand[current].remove_at(armed_card) ...
```
卡片使用机制（费用 / 入墓地 / 出手牌）仍留在 `cmd_at`，**技能效果全部由数据驱动**。

### 技能表补强（`battle_defs.SKILLS`）

- 电击 / 治疗：删除「依赖施放者单位」的条件（指令卡无施放单位，原条件会误判为不满足）
- 回收：targets 由 `any` 收窄为 `soldier`（不可回收蜂王），删除 `unit_op` 条件
- 新增 **`X费·毁灭`** 技能条目：`effects: [{type: damage, value: 0, by_target_cost: true}]`
  → 效果执行器新增 `by_target_cost`：伤害 = 目标部署费 × 2（**X 费特例从 cmd_at 移入技能数据**）

### 效果执行器（`battle_skills.apply_effect`）

- `damage` 支持 `by_target_cost`（X 费）；日志统一为「受指令伤害 -N」
- `modify` 支持 `instant_heal`（即时回复类，含生命上限钳制），与 buff 类共用同一效果类型
