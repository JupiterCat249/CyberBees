## 二、修复内容（提交 `29cf032`）

自检改为**断言表**（每项 `[名称, Callable]`），**总项数由表长得出**：

```gdscript
var checks: Array = [
	["开局准备注入 state.setup", func() -> bool: return state.setup != null],
	… 10 项 Model 注入 …
	# 迭代005 补：动画引擎注入（迭代004 高危接线——曾整体丢失且导致完全静默，属 G-01 事故族）
	["动画引擎注入 state.anim", func() -> bool: return state.anim != null],
	["动画引擎挂场景树", func() -> bool: return state.anim != null and state.anim.get_parent() != null],
	["动画节点解析回调注入", func() -> bool: return state.anim != null and state.anim.node_provider.is_valid()],
	["动画特效挂载点注入", func() -> bool: return state.anim != null and state.anim.fx_parent != null],
	# 迭代005 补：View 侧注入（此前完全没有断言）
	["背景注入 BgFx.setup()", …], ["棋盘视图注入 BoardView.setup()", …], ["手牌视图注入 HandView.setup()", …],
	["详情视图注入 DetailView.setup()", …], ["HUD 视图注入 HudView.setup()", …],
	# 接线类
	["输入路由 holder 注入", …], ["取消选中接线", …], ["长按详情浮窗接线", …],
	["浮窗关闭接线", …], ["投降取消接线", …], ["浮窗文本接线", …],
]
for c in checks:
	if not (c[1] as Callable).call():
		missing.append(str(c[0]))
if missing.is_empty():
	print("[BattleFlow] 接线自检通过（%d 项）" % checks.size())
```

**项数构成（实测 26 = 11 + 4 + 5 + 6）**：

| 组 | 项数 | 内容 |
|----|------|------|
| Model 注入 | 11 | `setup / victory / turn / interaction / grid / action / deploy / deck / pending / skills / combat` |
| **动画引擎**（本轮新增） | 4 | `state.anim` · 挂场景树 · `node_provider` · `fx_parent` |
| **View 注入**（本轮新增） | 5 | `BgFx` · `BoardView` · `HandView` · `DetailView` · `HudView` |
| 接线 | 6 | `holder` 注入 · 取消选中 · 长按浮窗 · 浮窗关闭 · 投降取消 · 浮窗文本 |

> 11 + 4 + 5 + 6 = **26**，与冷启动日志「接线自检通过（26 项）」一致 ✅（修复前实为 11+5=16 条断言、却打印"12 项"）
