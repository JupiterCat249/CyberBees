# tests/ —— 回归资产（工程文件，不是验证产物）

> 最后更新：2026-10-22
> 归属：质量门禁 G4（回归闸）。判定权归 `qc/qc.ps1`，不依赖 AI。

## 为什么放在这里，而不是 `verification/`

`verification/` 含 `.gdignore`（Godot 引擎会**完全忽略**该目录），这是为防"归档的 .gd 被当脚本加载→卡调试断点"
而设的硬隔离。代价是 **GUT 无法从那里加载测试**。因此：

| 类别 | 目录 | 性质 | 入版本库 | 进 CI |
|---|---|---|---|---|
| 回归资产 | `tests/` | 工程文件，长期维护 | ✅ | ✅ |
| 一次性验证产物 | `verification/` | 封存归档 | ✅（归档用） | ❌ |

## 约定

1. 文件名 `test_*.gd`，类 `extends GutTest`。
2. **只断言逻辑与结构事实**（节点存在、引擎状态、规则数值、信号契约）。
   **像素/观感/手感不进 CI**——依赖人的感官的结论交给人（AGENTS.md 独立评估节）。
3. 每个测试必须能独立跑：`qc/qc.ps1 test`（内部为 `godot --headless -s addons/gut/gut_cmdln.gd -gdir=res://tests -gexit`）。
4. 新增测试若发现实现缺陷：先提交**红**的测试（证明判据有效），再修实现。
5. 测试代码同样受 gdlint 约束（`qc lint` 会扫它）。
